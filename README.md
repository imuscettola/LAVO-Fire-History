This is a working file directory for all working code related to the LAVO 2022 Fire History project. The project was completed as a part of a Master's thesis "The Effects of Fire History and Burn Severity on Soil Bacterial Communities in Andisols of a Temperate Coniferous Forest" by Isabella Muscettola at the University of Wisconsin, Madison under the advisement of Dr. Thea Whitman. The electronic version of the MS thesis can be accessed at UW Madison University Libary https://minds.wisconsin.edu/handle/1793/95081](http://digital.library.wisc.edu/1793/95081.
